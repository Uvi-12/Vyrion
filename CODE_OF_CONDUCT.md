# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

We want Vyrion to be a welcoming, harassment-free space for everyone, regardless of background or experience level. Be kind, assume good faith, and focus on the work.

Report unacceptable behaviour to the maintainers through a private security advisory or the contact listed in `SECURITY.md`. Reports are handled confidentially.
